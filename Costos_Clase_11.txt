Ejercicio 6:
Bloque A — Bucle simple:
- El bucle itera exactamente n veces.
- Cada iteración hace una operación constante.
- Costo del Bloque A: O(n)

Bloque B — Bucles anidados:
- El bucle externo itera n veces.
- Por cada iteración del externo, el interno también itera n veces.
- Total de operaciones: n × n = n^2
- Costo del Bloque B: O(n^2)

Regla de la Suma:
T(n) = Bloque A + Bloque B
T(n) = O(n) + O(n^2)
T(n) = O(máx(n, n^2))
T(n) = O(n^2)


Ejercicio 7: 
Partimos de n elementos. Después de cada comparación, el problema se reduce a la mitad:

Paso 0:  n elementos   →  arreglo completo
Paso 1:  n/2           →  descartaste mitad izquierda o derecha
Paso 2:  n/4           →  dividís la mitad restante
Paso k:  n / 2^k       →  en algún momento llegás a 1 elemento

el peor caso es cuando el subarreglo restante tiene exactamente 1 elemento:
n / 2^k = 1

n = 2^k

Aplicando log₂ en ambos lados:

log2(n) = log2(2^k)
log2(n) = k · log2(2)
log2(n) = k · 1

k = log2(n)

La búsqueda binaria realiza como máximo log2(n) comparaciones, por lo tanto pertenece a la familia O(log n).

El término n^2 domina sobre n para todo n grande, por lo que n se descarta. La complejidad total del método es cuadrática: O(n^2).
